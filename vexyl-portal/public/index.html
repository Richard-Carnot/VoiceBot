Text-to-Speech Endpoint (`POST /v1/tts/generate`)

Synthesizes input text into high-fidelity 44.1kHz audio in base64 format using Carnot CR_voice model series.

POST /v1/tts/generate
Header: Authorization: Bearer vx_live_...
Body:
{
  "text": "नमस्ते",
  "model": "CR_voice1",
  "target_language": "hi-IN",
  "voice": "shubh",
  "pace": 1.0,
  "sample_rate": 44100
}

Speech-to-Text Endpoint (`POST /v1/stt/transcribe`)

Transcribes uploaded WAV/MP3 audio file or raw base64 PCM stream into text using Carnot CR_stt model series.

POST /v1/stt/transcribe
Header: Authorization: Bearer vx_live_...
FormData:
  file: 
  model: "CR_stt1"
  language_code: "hi-IN"

Translation Endpoint (`POST /v1/translate`)

Translates source text between 22 Indic languages and English using Carnot CR_trans engine on GPU.

POST /v1/translate
Header: Authorization: Bearer vx_live_...
Body:
{
  "text": "Hello, welcome.",
  "model": "CR_trans",
  "source_language": "English",
  "target_language": "Hindi"
}
